# CPTN — RSD Payroll System

ASP.NET Core 8 MVC payroll app for the CPTN capstone project.

## Clone and open

```bash
git clone https://github.com/jer2514/CPTN.git
cd CPTN
```

Open `RSDSystem.sln` in Visual Studio 2022 (or later) with the .NET 8 SDK.

Update `RSDSystem/appsettings.json` with your local SQL Server connection string, then run the project.
